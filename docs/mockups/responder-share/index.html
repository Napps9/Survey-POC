  2. 2

    One rule decides between the large preview and the small thumbnail on WhatsApp: a 1200×630 JPEG under 300 KB. The mockup card saves at ~120 KB at quality 82.§3

  3. 3

    iMessage previews are built on the sender's phone and need an absolute https image URL; the page's <title> is ignored in favour of og:title.

  4. 4

    Facebook's crawler is documented as honouring robots.txt, and X, LinkedIn and Slack's do — so Disallow: /play/ used to leave the four right-hand tiles with nothing. That line is now removed, so all seven can fetch the page; what they render still waits on the og: tags in §2.§4

    X trims the 1200×630 to 2:1 and overlays the title, so nothing important sits in the bottom 40px of the image.

  6. 6

§ What the boards imply — the spec for whoever builds it

Numbered to match the §n references in the notes. Everything here is still to build except §4, which has shipped — the rest is what the mockups commit to.

  1. 1
    Three share fields and an image mode on the Vertoshare_title (≤ 70), share_description (≤ 200), share_message (≤ 160), share_image_mode auto | custom, has_one_attached :share_image. Readers with fallbacks so a blank field gives today's behaviour: share_title_text → "theme · Playverto", share_description_text → description || theme, share_message_text → a default line from the locale files.
  2. 2
    The tag set on /play/:token and /test/:tokenog:type, og:site_name, og:locale, og:url (canonical, no query) + rel=canonical, og:title, og:description, og:image (absolute, /play/:token/share.jpg?v=updated_at), og:image:secure_url / type / width 1200 / height 630 / alt, twitter:card=summary_large_image, twitter:image + alt. Same owner-preview guard as today (show.html.erb:8). The page <title> stays as it is.
  3. 3
    One generated JPEG, cached per editAn SVG template (headline wrapped, org logo as a data URI, palette from BrandPalette.resolve, background photo fetched and composited) rendered by ruby-vips: svgload_buffer → jpegsave_buffer(Q: 82, strip: true), stepping quality down until ≤ 300 KB. TTF Alata/ABeeZee installed in the Dockerfile for fontconfig. Body from Rails.cache.fetch(["share-card", survey.id, survey.updated_at, org.updated_at]), Cache-Control: public, max-age=3600. Custom mode serves the upload as a 1200×630 variant. A defined?(Vips) guard falls back to a static JPEG in dev and CI.
  4. 4
    robots.txt no longer blocks /play/ · shippedDisallow: /play/ is gone from public/robots.txt (/test/, /invites/, /funder_invites/, /blazer stay); the X-Robots-Tag: noindex, nofollow header stays as the binding half. Two reasons it was the wrong tool: bots that honour robots.txt can't unfurl what they may not fetch; and a crawler that may not fetch a page never receives the noindex either, so a linked /play/ URL could still surface as a bare result. search_indexing_test.rb now asserts the absence, so re-adding the line fails a test. /test/ is still disallowed — Test Mode links are shareable too, so that is the next line to consider.
  5. 5
    Attribution without touching the cacheShare URL = play_survey_url(public_link_key) + "?via=r". The player reads via on load, keeps it in sessionStorage, strips it with history.replaceState, and adds share_source: "respondent" to the submit payload (player_controller.js:1221). The server whitelists it into a new indexed responses.share_source. og:url and canonical never carry the param. Per-sharer codes are v2.
  6. 6
    The share payload and every fallbacknavigator.share({title: share_title_text, text: share_message, url}) via new data attributes on the player root; never files:. The sheet is server-rendered into the cached page (per-Verto content only): wa.me/?text=, sms:?&body= / sms:?body=, mailto:, X intent, Facebook sharer, LinkedIn share-offsite, clipboard for Copy link / Copy message, More… → navigator.share hidden when absent, QR via verto_qr_svg.
  7. 7
    "Include my answer", opt-inOnly when show_comparison is on. Headline card = share_headline_card_index or the first yes/no card; the label from the respondent's own answers, the percentage from the results JSON the compare panel already fetches. Toggle default off.
  8. 8

Left out, and why

  • A separate square image. WhatsApp reads only the first og:image, and at 70px nothing is legible anyway; one crop-safe 1200×630 covers every platform.
  • files: in navigator.share. An attached image suppresses the link preview and turns the iOS sheet into photo-sharing. A "Save image" for Instagram Stories can come later, as its own control.
  • Share-tap analytics. Only a completed response is worth a column (§5). Taps are vanity.
  • Per-link and per-language share copy. The nil-means-inherit pattern on SurveyLink exists, but the thank-you copy isn't translated today either; v1 carries the default-locale text everywhere.
  • An Android share-sheet board. Same semantics as A3, nothing new to say.
  • Email as a phone tile. Behind More…; it comes forward on desktop (B2).
